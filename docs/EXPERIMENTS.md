## 当前默认训练配置

| 项目 | 设置 |
| --- | --- |
| 预训练模型 | YOLO11n |
| 数据配置 | configs/custom_data.yaml |
| epochs / imgsz / batch | 10 / 640 / 4 |
| device / workers / amp | cpu / 0 / False |

这些是脚本默认值，并非检测性能指标。数据划分默认最多抽样 100 张，未固定随机种子；正式比较时应保存实际划分清单。

## 结果记录内容

每次实验建议保留：

- **环境**：代码提交、Python、Ultralytics、PyTorch、OpenCV 版本，训练设备和推理设备。
- **数据**：来源与版本、各集合实际样本数、类别分布、划分清单。
- **配置**：预训练权重、训练参数、数据 YAML 与完整类别映射。
- **精度**：Precision、Recall、mAP50、mAP50-95，以及逐类结果和评估集说明。
- **速度**：输入尺寸、批大小、预热方式、前处理/推理/后处理计时范围和设备。
- **可视化**：真实预测样例、漏检与误检案例；注明模型、置信度阈值与数据来源。

当前没有填入精度或速度数值，也没有附带预测效果图。

## 产物组织

本地训练与检测结果保留在 `runs/`；该目录默认不跟踪。需要展示的结果可选取到 `assets/results/`，并在本页说明产生它的实验配置。模型权重可通过后续 Release 或其他明确的资源入口单独分发。

运行失败可使用运行问题 Issue 模板；记录新实验可使用实验记录模板。
