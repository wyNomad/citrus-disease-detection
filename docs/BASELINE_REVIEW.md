## 本轮修复

1. **导出格式模型的设备初始化**：Ultralytics 读取 ONNX 类别信息时可能初始化后端。原来仅在推理或评估调用中传设备，读取类别的步骤仍使用自动选择。现在公共检测器和独立评估在读取类别前写入指定设备；回归覆盖 CPU 与显式设备编号，真实 Ultralytics 初始化路径另验证 CPU 参数传递。
2. **数据准备的并发防覆盖**：原来的目录存在检查与后续复制之间有竞态。现在在复制前以 `exist_ok=False` 独占创建输出根目录；另一任务先创建同一目录时立即失败，保留该目录已有文件。回归通过模拟并发目录创建复现并验证。
